# 3.2 Поиск строк в файле по регулярному выражению с контекстом

Язык реализации — Perl.

## Что нужно сделать

Из консоли вводятся путь к файлу, регулярное выражение и количество строк контекста. Программа выполняет построчное чтение файла, находит совпадения и выводит номера найденных строк вместе с предшествующими и последующими строками. Результат сохраняется в отдельный файл. Если контексты соседних совпадений пересекаются, общие строки выводятся один раз.

## Данные и результат

- **На входе:** Путь к исходному файлу, регулярное выражение, количество строк контекста и путь к выходному файлу вводятся с клавиатуры.
- **На выходе:** Найденные строки с номерами и заданным контекстом в консоли и выходном файле. При отсутствии совпадений выводится соответствующее сообщение.
