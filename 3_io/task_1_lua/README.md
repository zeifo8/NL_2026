# 3.1 Построчное объединение нескольких текстовых файлов

Язык реализации — Lua.

## Что нужно сделать

Пользователь вводит имена исходных файлов и имя результирующего файла. Программа последовательно читает по одной строке из каждого файла и записывает их в выходной файл. Поддерживается обработка файлов различной длины и вывод количества обработанных строк. После достижения конца одного из файлов чтение продолжается из оставшихся файлов до тех пор, пока все они не будут прочитаны.

## Данные и результат

- **На входе:** Количество исходных файлов, их имена и имя выходного файла вводятся с клавиатуры.
- **На выходе:** Файл с чередующимися строками исходных файлов и количество записанных строк в консоли.
