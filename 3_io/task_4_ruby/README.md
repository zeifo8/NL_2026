# 3.4 Определение и преобразование форматов окончания строк

Язык реализации — Ruby.

## Что нужно сделать

Программа читает файл в бинарном режиме, определяет количество окончаний строк типов LF, CRLF и CR. Пользователь выбирает результирующий формат. Программа нормализует окончания строк, сохраняет содержимое в новый файл и выводит статистику выполненных преобразований. Последовательность CRLF учитывается как одно окончание строки, а не как два отдельных. Прочие байты файла остаются без изменений.

## Данные и результат

- **На входе:** Имя исходного файла, имя выходного файла и выбранный формат окончания строк (LF, CRLF или CR) вводятся с клавиатуры.
- **На выходе:** Файл с нормализованными окончаниями строк и количество исходных окончаний каждого типа.
