# 3.3 Работа с бинарным файлом записей фиксированной длины

Язык реализации — Nim.

## Что нужно сделать

Реализуются создание бинарного файла, добавление записей, чтение и изменение записи по её порядковому номеру. Каждая запись состоит из нескольких целочисленных полей фиксированного размера. Доступ к произвольной записи осуществляется посредством вычисления смещения в файле без чтения предыдущих записей. Нумерация записей начинается с единицы. Данные записываются в бинарном виде; смещение рассчитывается как произведение номера записи минус один на размер записи. При обращении к несуществующей записи выводится сообщение об ошибке.

## Данные и результат

- **На входе:** Имя бинарного файла, выбранная операция, номер записи и значения её полей вводятся через консольное меню. Для записи используются три 32-битных целых числа.
- **На выходе:** Созданный или изменённый бинарный файл, содержимое запрошенной записи и сообщения о выполнении операций.
