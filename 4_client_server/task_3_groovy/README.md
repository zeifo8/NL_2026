# 4.3 TCP-сервер проверки скобочных конструкций

Язык реализации — Groovy.

## Что нужно сделать

Сервер принимает от клиента текстовую последовательность, содержащую круглые, квадратные и фигурные скобки. С помощью стека проверяется корректность их вложенности. Клиенту возвращается результат проверки, а при обнаружении ошибки — позиция некорректной скобки. Взаимодействие реализуется через `Socket` и `ServerSocket`. Открывающие скобки добавляются в стек, для закрывающих проверяется соответствие верхнему элементу стека. В конце проверки стек должен быть пустым.

## Данные и результат

- **На входе:** Порт сервера, адрес сервера и строка со скобками, которую клиент вводит с клавиатуры.
- **На выходе:** Ответ сервера о корректности последовательности. Для неправильной последовательности — позиция первой ошибки или сообщение о незакрытой скобке с её позицией.
