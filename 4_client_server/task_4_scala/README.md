# 4.4 Передача бинарных файлов по TCP

Язык реализации — Scala.

## Что нужно сделать

Клиент устанавливает соединение с сервером и отправляет имя файла, его размер и содержимое. Сервер принимает данные блоками, записывает их в файл и проверяет соответствие полученного количества байтов заявленному размеру. После завершения передачи клиенту отправляется подтверждение либо сообщение об ошибке. Имя и размер файла передаются перед его содержимым, чтобы сервер мог определить границы передачи. Сервер сохраняет только имя файла без пути к исходному каталогу.

## Данные и результат

- **На входе:** Порт сервера, каталог для приёма файлов, адрес сервера и путь к передаваемому файлу задаются при запуске соответствующих программ.
- **На выходе:** Полученный бинарный файл на стороне сервера, количество принятых байтов и сообщение об успешной передаче или ошибке на стороне клиента.
