# 4.4 Сервер совместных таймеров обратного отсчёта с подписками клиентов

Язык реализации — Scala.

## Что нужно сделать

Сервер принимает подключения клиентов по TCP. Клиенты могут создавать именованные таймеры с заданной продолжительностью, подписываться на существующие таймеры и отписываться от них. Сервер хранит состояние таймеров и каждую секунду отправляет подписанным клиентам оставшееся время. При завершении обратного отсчёта клиентам отправляется соответствующее уведомление. Для сетевого взаимодействия используются стандартные средства `java.net`.

## Данные и результат

- **На входе:** Порт сервера, адрес сервера для клиента, команды создания таймера (имя и продолжительность в секундах), подписки и отписки (имя таймера).
- **На выходе:** Подтверждения команд или сообщения об ошибках, оставшееся время и уведомления о завершении таймеров для подписанных клиентов.
