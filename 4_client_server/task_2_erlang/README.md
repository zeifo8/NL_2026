# 4.2 UDP-сервер вычисления контрольных сумм

Язык реализации — Erlang.

## Что нужно сделать

Клиент отправляет серверу датаграмму, содержащую данные. Сервер с использованием `gen_udp` принимает сообщение, вычисляет контрольную сумму CRC32 и возвращает её клиенту. Клиент сравнивает полученное значение с локально вычисленной контрольной суммой. Предусматривается обработка тайм-аута ожидания ответа. Для расчёта CRC32 используются средства Erlang. Клиент вычисляет контрольную сумму тех же байтов, которые были отправлены серверу.

## Данные и результат

- **На входе:** Порт сервера, адрес сервера и строка данных, которую клиент отправляет в виде UDP-датаграммы.
- **На выходе:** Контрольная сумма CRC32 от сервера, локальная контрольная сумма и результат их сравнения либо сообщение о тайм-ауте.
