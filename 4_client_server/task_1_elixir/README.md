# 4.1 TCP-сервер синхронизации клиентов по барьеру

Язык реализации — Elixir.

## Что нужно сделать

Сервер принимает подключения нескольких клиентов с использованием `:gen_tcp`. Каждый клиент отправляет сообщение о готовности. После получения сообщений от заданного количества клиентов сервер разрешает им продолжить выполнение посредством отправки общего сигнала. После завершения цикла состояние барьера сбрасывается. Каждый клиент учитывается один раз за цикл. Для следующего цикла клиенты могут повторно отправить сообщение о готовности.

## Данные и результат

- **На входе:** Порт сервера и необходимое число клиентов задаются при запуске сервера. Клиенты получают адрес и порт сервера и отправляют сообщение READY.
- **На выходе:** Сообщение о снятии барьера для каждого клиента после получения запросов от всех участников, сообщения о готовности и завершении цикла на сервере.
