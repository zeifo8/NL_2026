# 5.1 Преобразование изображений PGM в PBM

Язык реализации — Swift.

## Что нужно сделать

Программа разбирает текстовый формат изображения PGM (P2), включая заголовок, размеры и значения яркости пикселей. По заданному порогу яркости каждый пиксель преобразуется в чёрный или белый. Полученное изображение сохраняется в формате PBM (P1). Пиксели с яркостью ниже заданного порога становятся чёрными (1), остальные — белыми (0). При чтении учитываются пробельные символы и комментарии формата.

## Данные и результат

- **На входе:** Имя входного PGM-файла формата P2, имя выходного PBM-файла и порог яркости в диапазоне от 0 до максимального значения яркости исходного изображения.
- **На выходе:** Изображение в текстовом формате PBM (P1) с исходными размерами.
