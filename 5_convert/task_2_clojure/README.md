# 5.2 Преобразование списка смежности графа в формат DOT

Язык реализации — Clojure.

## Что нужно сделать

Программа читает текстовый файл, содержащий список смежности графа. Из исходных данных формируются вершины и рёбра, устраняются повторяющиеся рёбра неориентированного графа. Результат сохраняется в формате DOT, пригодном для визуализации графа. Вершины без соседей также включаются в выходной файл. Для неориентированного графа пары A–B и B–A считаются одним ребром.

## Данные и результат

- **На входе:** Имя входного файла со списком смежности в формате `вершина: сосед1 сосед2 ...` (одна вершина на строку) и имя выходного файла.
- **На выходе:** DOT-файл с вершинами и рёбрами неориентированного графа без повторяющихся рёбер, включая изолированные вершины.
