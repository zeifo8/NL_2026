# 5.3 Преобразование постфиксной записи выражений в префиксную

Язык реализации — Scheme.

## Что нужно сделать

Арифметическое выражение в постфиксной записи разбивается на операнды и операторы. С использованием стека формируется вложенная структура выражения, которая затем выводится в префиксной форме. Поддерживаются основные арифметические операции и обработка некорректных выражений. При встрече оператора из стека извлекаются два операнда, из них строится новое выражение. Например, запись `2 3 + 4 *` преобразуется в `(* (+ 2 3) 4)`.

## Данные и результат

- **На входе:** Арифметическое выражение в постфиксной записи, в котором числа и операторы +, -, *, / разделяются пробелами.
- **На выходе:** Выражение в префиксной записи с сохранением структуры операций либо сообщение о некорректном выражении.
