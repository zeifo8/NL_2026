# 5.4 Преобразование последовательностей FASTA в TSV

Язык реализации — Common Lisp.

## Что нужно сделать

Программа разбирает текстовый файл формата FASTA, выделяя заголовки записей и соответствующие последовательности. Многострочные последовательности объединяются в одну строку. Результат сохраняется в TSV-файл со столбцами идентификатора, последовательности и её длины. Каждая запись начинается с заголовка, обозначенного символом `>`. Длина вычисляется после объединения всех строк последовательности.

## Данные и результат

- **На входе:** Имя входного FASTA-файла и имя выходного TSV-файла. Идентификатором считается первое слово после символа `>` в заголовке.
- **На выходе:** TSV-файл с заголовком таблицы и столбцами идентификатора, последовательности и длины последовательности.
