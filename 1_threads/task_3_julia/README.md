# 1.3 Параллельное численное интегрирование методом трапеций

Язык реализации — Julia.

## Что нужно сделать

Интервал интегрирования разбивается на участки, вычисления на которых выполняются параллельно с использованием `Threads.@threads`. Частичные результаты объединяются в итоговое значение интеграла. Сравниваются точность и время выполнения последовательного и параллельного алгоритмов. Для проверки точности используется интеграл функции x² на заданном интервале, точное значение вычисляется по первообразной. Обе версии используют одинаковое число разбиений.

## Данные и результат

- **На входе:** Границы интегрирования и число разбиений задаются аргументами командной строки. Для проверки используется функция f(x) = x², число потоков задаётся при запуске Julia.
- **На выходе:** Приближённое значение интеграла, абсолютная погрешность относительно точного значения, время последовательного и параллельного вычисления.
