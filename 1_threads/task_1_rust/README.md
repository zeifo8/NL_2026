# 1.1 Параллельное построение гистограммы байтов

Язык реализации — Rust.

## Что нужно сделать

Массив байтов разделяется на части, каждая из которых обрабатывается отдельным потоком с использованием `std::thread`. Каждый поток формирует локальную гистограмму из 256 элементов. После завершения потоков результаты объединяются. Сравниваются результаты и время выполнения последовательной и параллельной реализаций. Для сравнения обе версии работают с одним и тем же массивом. Число потоков задаёт пользователь.

## Данные и результат

- **На входе:** Размер массива и число потоков задаются аргументами командной строки. Массив заполняется псевдослучайными байтами.
- **На выходе:** Гистограмма частот байтов от 0 до 255, время последовательного и параллельного вычисления, результат сравнения гистограмм.
