# 1.1 Параллельное вычисление матрицы расстояний Хэмминга для набора строк

Язык реализации — Rust.

## Что нужно сделать

Для набора строк одинаковой длины строится матрица попарных расстояний Хэмминга. Строки результирующей матрицы распределяются между потоками с использованием `std::thread`. Расстояние определяется количеством несовпадающих символов на одинаковых позициях. После завершения потоков результаты объединяются и сравниваются с последовательной реализацией.

## Данные и результат

- **На входе:** Набор непустых ASCII-строк одинаковой длины и число потоков.
- **На выходе:** Матрица попарных расстояний, результат сравнения последовательной и параллельной реализаций.
