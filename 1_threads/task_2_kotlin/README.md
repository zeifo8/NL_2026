# 1.2 Параллельное обнаружение пиков во временном ряду

Язык реализации — Kotlin.

## Что нужно сделать

Массив числовых значений разделяется на участки, каждый из которых обрабатывается отдельным потоком. Пиком считается элемент, значение которого строго больше значений обоих соседних элементов. Учитываются элементы на границах участков. Найденные пики объединяются и сравниваются с результатом последовательного поиска.

## Данные и результат

- **На входе:** Массив числовых значений и число потоков.
- **На выходе:** Индексы и значения найденных пиков в порядке следования в массиве, результат сравнения с последовательным поиском. Первый и последний элементы не рассматриваются как пики.
