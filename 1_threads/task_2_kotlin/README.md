# 1.2 Параллельное вычисление префиксных сумм

Язык реализации — Kotlin.

## Что нужно сделать

Исходный массив разделяется на блоки, для каждого из которых в отдельном потоке вычисляются локальные префиксные суммы. После определения сумм предыдущих блоков выполняется параллельная корректировка элементов. Результат сравнивается с последовательным вычислением. Сначала каждый поток обрабатывает свой блок, затем по суммам блоков вычисляются смещения для корректировки. Например, для массива `2 3 1 4` результатом будет `2 5 6 10`.

## Данные и результат

- **На входе:** Целочисленный массив и число потоков. Размер массива и его элементы вводятся с клавиатуры.
- **На выходе:** Массив префиксных сумм и результат сравнения с последовательным алгоритмом.
