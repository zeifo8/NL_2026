# 1.4 Параллельное кодирование методом RLE

Язык реализации — D.

## Что нужно сделать

Входная последовательность символов разделяется на блоки, каждый из которых независимо кодируется методом Run-Length Encoding с использованием `std.parallelism`. После завершения обработки соседние серии одинаковых символов на границах блоков объединяются. Проверяется возможность восстановления исходной последовательности. Например, строка `AAABBCCCCA` кодируется как `A3 B2 C4 A1`. При объединении блоков необходимо учитывать, что одна серия может находиться сразу в нескольких блоках.

## Данные и результат

- **На входе:** Строка из символов ASCII и число блоков для параллельной обработки вводятся с клавиатуры.
- **На выходе:** Закодированная последовательность пар (символ, количество повторений), восстановленная строка и результат проверки совпадения с исходной.
