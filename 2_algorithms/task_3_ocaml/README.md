# 2.3 Топологическая сортировка графа алгоритмом Кана

Язык реализации — OCaml.

## Что нужно сделать

Ориентированный граф задаётся списком вершин и рёбер. Для каждой вершины вычисляется входная степень. Вершины с нулевой входной степенью последовательно добавляются в результат с обновлением степеней соседних вершин. При наличии цикла программа сообщает о невозможности топологической сортировки. Для хранения вершин с нулевой входной степенью используется очередь. Если в результате обработано меньше вершин, чем было задано, граф содержит цикл.

## Данные и результат

- **На входе:** Количество вершин и список ориентированных рёбер, вводимые с клавиатуры. Вершины нумеруются от 1 до n.
- **На выходе:** Один из допустимых порядков вершин или сообщение о наличии цикла.
