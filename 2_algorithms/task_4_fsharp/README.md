# 2.4 Поиск наибольшей возрастающей подпоследовательности

Язык реализации — F#.

## Что нужно сделать

Методом динамического программирования для каждого элемента массива определяется длина наибольшей возрастающей подпоследовательности, заканчивающейся этим элементом. С помощью массива предшественников восстанавливается сама подпоследовательность. Выводятся её длина и элементы. Подпоследовательность не обязана состоять из соседних элементов, но порядок элементов исходного массива сохраняется.

## Данные и результат

- **На входе:** Непустой массив целых чисел, вводимый с клавиатуры.
- **На выходе:** Длина наибольшей строго возрастающей подпоследовательности и один из вариантов самой подпоследовательности.
