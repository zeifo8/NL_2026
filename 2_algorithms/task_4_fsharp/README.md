# 2.4 Поиск самой длинной чередующейся подпоследовательности

Язык реализации — F#.

## Что нужно сделать

Для заданного массива целых чисел методом динамического программирования находится подпоследовательность максимальной длины, в которой строгое возрастание и убывание соседних элементов чередуются. Для восстановления элементов подпоследовательности используются индексы предшественников. Порядок элементов исходного массива сохраняется.

## Данные и результат

- **На входе:** Непустой массив целых чисел.
- **На выходе:** Длина и один вариант самой длинной чередующейся подпоследовательности.
