# 2.2 Рекурсивное решение задачи точного покрытия (рекурсия)

Язык реализации — Prolog.

## Что нужно сделать

Задаётся множество элементов и набор его подмножеств. Необходимо выбрать подмножества таким образом, чтобы каждый элемент исходного множества входил ровно в одно выбранное подмножество. Решение ищется рекурсивным перебором с возвратом.

## Данные и результат

- **На входе:** Конечное множество элементов и список его непустых подмножеств.
- **На выходе:** Один набор подмножеств, образующий точное покрытие, либо сообщение об отсутствии решения.
