# 2.2 Раскраска графа перебором с возвратом (рекурсия)

Язык реализации — Prolog.

## Что нужно сделать

Неориентированный граф задаётся списком рёбер. Рекурсивный алгоритм назначает каждой вершине один из заданных цветов, проверяя отсутствие конфликтов между смежными вершинами. При невозможности назначения выполняется возврат к предыдущему состоянию. Выводится допустимая раскраска либо сообщение об отсутствии решения. Вершины обрабатываются по очереди. Для каждой из них перебираются цвета от 1 до заданного количества, пока не найдётся допустимый вариант.

## Данные и результат

- **На входе:** Число вершин, список рёбер неориентированного графа и число доступных цветов.
- **На выходе:** Цвет каждой вершины или сообщение о том, что раскраска заданным количеством цветов невозможна.
