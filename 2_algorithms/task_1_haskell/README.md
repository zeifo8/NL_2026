# 2.1 Генерация правильных скобочных последовательностей (рекурсия)

Язык реализации — Haskell.

## Что нужно сделать

Для заданного числа пар скобок рекурсивно строятся все допустимые скобочные последовательности. На каждом шаге проверяется возможность добавления открывающей или закрывающей скобки. Выводятся полученные последовательности и их количество. Рекурсия заканчивается, когда использовано n открывающих и n закрывающих скобок. Закрывающая скобка добавляется только при наличии незакрытой открывающей.

## Данные и результат

- **На входе:** Неотрицательное целое число n — количество пар круглых скобок.
- **На выходе:** Все правильные последовательности из n пар скобок и их общее количество.
